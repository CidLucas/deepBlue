# Referências — Marcas

Marcas de referência citadas pelo Lucas como inspiração de design.

| Marca | Origem | O que extrair |
|---|---|---|
| MESA | mesa.do | Clean/editorial: grid generoso, tipografia expressiva, hierarquia quieta |
| Zerezes | zerezes.com | Minimalismo preto, zero desperdício, atenção a pixels |

## Regra

Antes de propor qualquer artefato de comunicação, conferir se a referência
aqui se aplica — o padrão do Lucas: "interessante mas feio" = manter o
conceito, cortar decoração/movimento/cores saturadas.
